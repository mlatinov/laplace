$ laplace doc langevin::barker
langevin::barker  (langevin 0.1.0, kernels/barker.lapkernel)

  Barker proposal: gradient-informed and robust to a mistuned step size

Tuning values (set as `name = value` after the kernel, e.g. in a .lapsampler):
  real<lower=0> eps = 1   @adapt(step_size, target_accept = 0.4)
      Step size (adapted toward 0.4 acceptance)
  vector<lower=0>[dim] m = rep_vector(1, dim)   @adapt(metric)
      Diagonal inverse metric (adapted in warmup)

Step: ends in propose(): a Metropolis-Hastings proposal; laplace-sample accepts or rejects it (one uniform).
Adaptation: adapt(langevin::barker) tunes eps and m in warmup, then freezes them.

  hmc    settings: step_size, steps, jitter; adapt(hmc()) tunes step size and metric (target 0.8)

langevin 0.1.0 (`import langevin`):
  langevin::barker     tuning: eps @adapt(step_size, target_accept = 0.4), m @adapt(metric)
      Barker proposal: gradient-informed and robust to a mistuned step size
  langevin::mala       tuning: eps @adapt(step_size, target_accept = 0.574), m @adapt(metric)
      Metropolis-adjusted Langevin algorithm with a diagonal metric

$ cat hybrid.lapsampler
    sampler survival_hybrid {
      library { import langevin }
      kernel {
        block(eta0, beta) as reg : adapt(langevin::mala)
        rest                     : adapt(langevin::barker)
      }
      warmup { iterations = 1000; }
      draws  { iterations = 5000; }
    }
